# 田间手记 · Farm RL

一款和 AI 对弈的像素农场游戏。开局可选 **Starter**（官方入门）、**BC**（行为克隆）或 **PPO**（第 1200 轮）。

**[下载 Windows 离线版](https://github.com/Dengthlk/Farm-RL/releases/latest/download/Farm-RL-Game-Windows-x64.zip)** · 支持 Windows 10/11 x64。完整解压 ZIP，双击 **开始游戏.cmd**，浏览器会自动打开。运行环境和模型已包含在包内。

## 游戏规则

- 双方各有 **$3,000**，共用一个市场。赛季为 **30 天**，结束时现金多的一方获胜，现金相同则平局。
- 移动一格或做一次农活消耗一个回合，AI 同时行动。点击目的地可连续行走，途中可排入农活，按 **Esc** 取消后续动作。
- 去集市买一颗胡萝卜种子，找块空地播种，当天浇水。成熟后收获进背包，送回仓库即可出售。日末背包会自动入仓。
