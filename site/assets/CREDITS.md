# Pixel art credits

This game uses unmodified 16×16 pixel sprites from:

- **Kenney Tiny Farm 1.0** — https://kenney.nl/assets/tiny-farm
- **Kenney Tiny Town 1.1** — https://kenney.nl/assets/tiny-town

Both packs are licensed under **Creative Commons Zero (CC0)**. Original license files are retained in each pack's directory. Downloaded from the author's website, 2026-11-06.

The scene layout, pond, field textures, selection markers, interface and game integration were created for this project. A few sprites are reused as visual approximations (e.g. the poultry sprite for goose and the tomato sprite with a color filter for strawberry); item names and rules remain authoritative.

Design research: **Seasons Gone**, an open-source top-down farming game by Elliot Fontaine, https://github.com/elliotfontaine/untitled-farming-sim . No code or assets from that repository are redistributed here.
